# Product photos before the October photoshoot

`donsan-product-photos-before-2026-11-05.zip` preserves all 34 product images used by the site before this refresh, the combo artwork, and the previous image-source records.

The ZIP includes `manifest.json` with product IDs, paths, sizes, SHA-256 checksums, and the source Git commit. Files inside the archive retain their original paths. The archive was verified before any photo references changed.

The new gallery selection and photographer credits are recorded in `assets/photoshoot-2026-10-29/manifest.json`. Existing unused source images in `assets/` and `card-images/` are preserved separately.
